The programs, in detail

Four programs of 8 to 12 weeks, written on real queries and real questions.

Program 01 · From joins to windows

SQL that sticks

We build SQL from the inside: what a join actually does to row counts, when aggregation lies to you, readable CTEs instead of nested subqueries, and window functions — which unlock most of the analysis people think requires a scripting language.

  • 10 weeks
  • Beginners welcome
  • 5 hours a week
  • Any SQL database

Program 02 · The question behind the question

Doing an analysis

An analysis starts with the decision someone needs to make. We work on getting to that, on cleaning data without quietly deleting the inconvenient rows, on choosing metrics that can't be gamed, and on stating limitations plainly — which builds far more trust than confident overreach.

  • 10 weeks
  • Comfortable with SQL
  • 5 hours a week
  • A dataset you care about

Start this program

Program 03 · Used, not built and forgotten

Dashboards & reports

Most dashboards are a wall of charts nobody opens twice. We work on choosing the right chart, on layout and hierarchy, on documenting metric definitions so numbers stop being argued about, and on keeping a dashboard maintainable after you've moved on.

  • 8 weeks
  • Some analysis experience
  • 4 hours a week
  • Any BI tool

Program 04 · Findings people act on

Working with stakeholders

Good analysis dies in bad communication. We work on scoping requests before starting, writing a summary that leads with the answer, presenting to people who want a decision rather than a method, and handling the pushback that arrives when findings are inconvenient.
